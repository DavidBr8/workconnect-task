# workconnect-task

Katalog produktów. Aplikacja Next.js.

## Wymagania

- Node.js 20.9 lub nowszy
- npm

## Uruchomienie lokalne

W katalogu projektu:

```bash
npm install
npm run dev
```

Aplikacja działa pod adresem [http://localhost:3000](http://localhost:3000). Katalog produktów jest pod adresem [http://localhost:3000/products](http://localhost:3000/products).
